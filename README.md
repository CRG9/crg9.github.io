Interactive Timeline Builder
A front-end project built with vanilla JavaScript, HTML, and CSS to create, edit, and reorder timeline modules dynamically.

Project Purpose
This project was developed as a hands-on exercise to deepen my understanding of JavaScript's interaction with the DOM. The primary goal was to build a fully interactive web application from scratch, focusing on:

DOM Manipulation: Dynamically creating, updating, and deleting HTML elements in response to user actions.

Event Handling: Managing user input through clicks, form submissions, and keyboard events.

State Management: Keeping the UI synchronized with an underlying JavaScript data array (timelineArray).

Responsive Design: Using CSS Grid, Flexbox, and media queries to ensure the application is usable on both desktop and mobile devices.

Development & Learning
Throughout the development process, I used Google's Gemini as a pair-programming assistant. It was instrumental in helping me:

Debug efficiently: Quickly identifying issues with layout, event listeners, and data handling.

Solve complex problems: Implementing features like keyboard-based reordering and creating custom confirmation modals.

Refactor for cleaner code: Turning repetitive code into reusable functions and adopting more modern JavaScript practices.

This approach allowed me to overcome challenges faster and focus on the core logic and learning objectives of the project.

Core Features
Create Modules: Add new events to the timeline through a form.

Select & View: Click any module to see its details in a dedicated display area.

Edit Modules: Modify the name, description, and date of any existing module.

Delete Modules: Remove modules from the timeline.

Reorder Modules: Use arrow keys on desktop or on-screen buttons on mobile to change the order of modules.

Responsive Layout: The interface adapts from a horizontal timeline on desktop to a vertical list.

Reset Timeline: Completely wipe all data and visuals after a confirmation message is provided.
